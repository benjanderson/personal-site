## Deployment Instructions

To deploy this site, follow these steps:

1. **Build the project**

```sh
npm run build
```

This will generate the production files in the `dist/` directory.

2. **Deploy the `dist/` folder to your web host**

- You can use any static hosting provider (e.g. Vercel, Netlify, GitHub Pages, or your own server).
- Upload the contents of the `dist/` folder to your hosting provider.

## Debug Instructions

To debug the site locally:

1. **Install dependencies**

   ```sh
   npm install
   ```

2. **Start the development server**

```sh
npm run dev
```

This will start Vite's development server. Open the URL shown in your terminal (usually http://localhost:5173) in your browser.
